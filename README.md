# Ripple

Horgásztavak, versenyek és fogási napló Vajdaságnak (szerb és magyar nyelven).

- Weboldal + telepíthető alkalmazás (PWA), build nélkül: `index.html`, `css/`, `js/`
- Háttér: Supabase (adatbázis, belépés, fotók)
- Térkép: Leaflet + OpenStreetMap

Oldalak: `#/` tavak, `#/jezero/<slug>` tó, `#/takmicenja` versenyek, `#/dnevnik` fogási napló,
`#/moja-jezera` saját tavak, `#/admin` jóváhagyás, `#/prijava` belépés, `#/profil` profil.
